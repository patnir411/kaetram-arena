# Kaetram Arena — Research Knowledge Base

Compiled knowledge for the this research project. Two independent papers: Paper 1 (Kaetram distillation, ICLR 2027) and Paper 2 (RuneScape adversarial multi-agent, planned).

**Rule:** After any training run, data rebuild, or design decision, update the relevant file here. If no file fits, create one and link it below. Without this, the wiki dies.

**Reliable maintenance flow:**
- LLM compile pass when explicitly requested: `.claude/commands/compile-research.md`
- Cheap VM-safe staleness check: `python3 scripts/check_research_staleness.py`
- VM-safe staleness check with email nudge: `python3 scripts/check_research_staleness.py --notify`
- VM cron-friendly wrapper: `scripts/run_research_staleness_check.sh`

The durable loop is VM cron + the wrapper. The wrapper first runs the staleness checker, then auto-invokes Claude Code with `/compile-research` using `claude-opus-4-6` when stale if Claude CLI is installed and authenticated on the VM. If research files changed, it stages `research/` + `session_log.md`, commits, rebases, and pushes. If Claude CLI is unavailable, it falls back to an email nudge.

## Methodology shift at r10

**r1-r9 were largely vibe-coded** — fast exploratory cycles with minimal formal process. Real wins landed (loss masking, observe supervision, prompt parity), but decisions, data choices, and patch motivations were rarely written down. r10 marks the methodological shift: tool surface centralized in `tool_surface.py`, decisions logged in `research/decisions/`, data filters justified empirically against the live corpus, no iteration-history comments left in code, and the pipeline (`extract_turns.py` + `convert_to_qwen.py`) was rewritten without fossils.

- [opd-2b.md](experiments/opd-2b.md) — **OPD rounds 1–3 (Jun 7–14 2026, complete).** The pivot off 9B/r10-repair to a clean capability-instillation test: teacher = scaffolded 4B (17/30), student = base 2B (12/30). **Core-3 arc base 12 → r1 12 → r2 15 → r3 18 (best of program; a clear step beyond base — two quest chains cleared unseeded vs base's one — from a 2B).** *Round 1* (style transferred, competence didn't): 12/30 flat but landed on the teacher's distribution; diagnosis = **visitation coupling** + the **teacher-forcing copy-prior** (the 4B *prefers* the student's malformed `accept_quest_offer` syntax in-context — reverse-KL can't self-correct a teacher-shared defect; novel observation). *Round 2* (visitation fix): seeded bucket-B at the Herbalist wall → **first weights-driven lift, stage-1 passed 3/3 unseeded (15/30)**; abstention masking *contained-not-cured* the format defect (it mutated to `<function=name("arg")>`). *Round 3* (counterfactual grading + full-ladder seeding + harness recovery): broke the **Herbalist stage-2 wall (all 3 → 3/3)** via correct cluster coord + nav-stall recovery; **counterfactual grading REGRESSED the malformed emission** (grader-suppression didn't transfer to generation) but a **harness recovery affordance fixed it** (405 recovered, self-correcting, zero relapse) — the harness+weights co-evolution thesis made concrete. Over base the **+6 decomposes +3 pure weights (r2, the wall) / +2 harness / +1 r3 weights** — weights are the competence engine; a controlled ablation (**r2 weights + recovery = 17/30**) shows that *within the r2→r3 step* the harness carried ~2 stages and the r3 weight update ~1 (whose payoff is ~2× speed, +40% throughput). We label 18/30 weights-plus-interface and don't lean on edging the 4B teacher (18 vs 17). **Rick's Roll stayed 0/4**: 3-link execution failure (pole never re-equipped → 0 shrimp → 0 cook; cook = 0 transfer, exactly as predicted for a cook-incompetent same-family teacher). Reasoning became a *third shape* (concise, churn halved, `</think>` dialect abandoned, grounding preserved). Round 4 (evidenced): privileged-context grading (Claude trajectory in the teacher's grading context) + two cheap harness fixes. **Cost (billing-verified): r1–r3 = $160 incl. all debugging (r1 $111 — broken-kernel 3× retrain — / r2 $33 / r3 $16; ~44% of one r10 cycle); fast-kernel round build+train ~$5–10.** Operational chain: `dataset/opd_2b/ROUND1_RUNBOOK.md`; paper: `reference/overview.pdf`

## Recent Major Changes (Apr 24 – May 22, 2026)

- **r10-SFT vs base headline result (May 19–22, finalized).** Clean comparison (n=4 base / n=3 SFT, all 3h+) after `play_qwen.py` JSON-dict fix landed in `7bf7c8d`. Base (all 4 runs identical): `(grinder=1, completionist=3✅, explorer=3✅) = 7/30 Core 3 stages`. SFT (n=3 clean): `[3, 1, 2]`, mean **2.0/30**, std 1.0. **3.5× drop on Core 3 stages**: Mann-Whitney exact per-run **p=0.029** (scipy's default returns the tie-degraded 0.016 — base is all-7s; use `method='exact'`; the per-agent p=0.001 is dropped as pseudo-replicated). Fisher Foresting completion (8/12 vs 1/9) **p=0.016, OR=16**. Foresting completion rate: **67% base → 11% SFT, 6.0× drop**. Mechanism: completionist `interact_npc` collapsed 5.6× (63.3 → 11.3) and `query_quest` collapsed 4.8× (65.7 → 13.7), while `navigate` was *amplified* 4.49× (32 → 143.7). **Fingerprint: SFT inference matches the training-target distribution within ~1pp on the decision verbs** (interact_npc 2.4% ↔ SFT 2.1%, query_quest 2.2% ↔ 2.5%, navigate 27.7% ↔ 26.4%; observe is the exception at 8pp). Base runs the dialogue verbs ~5× more often (10.8%, 11.2%) — chat-model prior leaks through. This is the **corpus-prior-becomes-inference-prior** result — capability suppression on the verbs the corpus under-represented (cf. Kotha ICLR'24, "Awakening the Sleeping Agent" '26). Numbers reproducible via `scripts/r10_stats.py`. Full data in `research/experiments/r10-discussion.md`.
