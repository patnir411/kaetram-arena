# Local trigger-incidence diagnostic

Status: registered before outcomes; no endpoint contacted at registration.

The completed 18-cell local recovery factorial produced zero recovery
opportunities in 958 generations. That is a failed manipulation check: an
on/off recovery comparison cannot identify a recovery effect when the recovery
path never runs.

This zero-cost follow-up asks a narrower question before any further gameplay
budget is spent: does the malformed-call trigger appear when we cross two
model-visible interface choices at matched historical decision states?

- historical Python-call-like tool documentation versus canonicalized prose;
- no native `tools` block versus the complete frozen native tool schema;
- fixed Base, OPD round-2, and OPD round-3 public checkpoints.

Twenty deterministic completionist-policy historical states receive five
paired sampling seeds in all four interface conditions: 100 responses per
condition and 1,200 total.
Checkpoint identity, source-log hashes, rendered-state hashes, request seeds,
raw response messages, and all failures are retained. Only loopback endpoints
are allowed.

The primary outcome exactly matches the runtime recovery gate: no structured
tool call plus at least one candidate from `recover_tool_calls(content)`.
Malformed text alone is secondary because not every malformed string is
executable. Each checkpoint has three registered finite-grid contrasts:
native-schema effect, documentation effect, and their interaction.

The historical states can be temporally dependent observations from one run,
so they are not treated as independent population draws. The analysis reports
exact rates and paired differences on the fixed 20-state × five-seed grid,
plus the number of states with positive, negative, or zero differences. It
reports no p-values, confidence intervals, binomial bounds, or population
uncertainty. Rotating condition order balances deterministic execution order;
it is not random assignment. The 100 requests per cell match the scale of the
earlier unverified development probe for direct diagnostic comparison, not as
a power claim.

The study can establish an inference-time interface effect conditional on the
fixed state pool and checkpoints. It cannot establish a checkpoint or training
method advantage, a recovery benefit, learned self-correction, quest
improvement, or generalization. If the trigger remains absent, the natural
recovery factorial is scientifically nonviable under this interface; a
controlled defect-injection study would answer a different conditional
question.

Machine-readable registration:
[`local-trigger-incidence-v1.json`](local-trigger-incidence-v1.json).

The workflow is deliberately two-stage:

1. Prepare and hash the outcome-free state design.
2. After the registration/code revision is clean and merged, run one
   hash-attested local checkpoint at a time and analyze only when all 1,200
   scheduled requests are present.

## Outcome update

All 1,200 requests completed with zero failures and stable checkpoint identity.
The sealed analysis was reproduced byte for byte, and a separately implemented
auditor recomputed all response labels, cells, and registered contrasts from
the checked-in raw rows.

Native-schema exposure changed recoverable content-only call incidence by +30,
+22.5, and +15 percentage points for Base, round 2, and round 3. Canonical
documentation changed it by 0, -7.5, and +10 points. These are descriptive
effects on the frozen state grid.

A post-outcome seed-diversity audit found one semantic response in every
five-seed state-condition group. The request seed had no observable effect
under this serving path. Duplicate responses are therefore collapsed to 20
state outputs per cell; cell rates and state-level contrasts are unchanged, but
there is no stochastic sampling uncertainty.
