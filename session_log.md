## 2026-05-11 — log_analysis decoder fix for qwen wire format

`scripts/log_analysis/parse.py:decode_tool_result_content` only handled Claude's `{"result": "<inner>"}` tool_result wrapper. Qwen harness writes raw MCP output bare (no wrapper), so observe payloads — which carry `<JSON>\n\nASCII_MAP:<grid>` — failed `json.loads` with "Extra data" and degraded to raw strings. Result: `latest_observe()` returned None for every qwen session; analyzer reported `?` for lvl/hp/pos and `untouched` for quests on every qwen run. Fixed with a 4-branch decoder (Claude wrapper / qwen non-observe dict / qwen observe with ASCII suffix / plain string).
